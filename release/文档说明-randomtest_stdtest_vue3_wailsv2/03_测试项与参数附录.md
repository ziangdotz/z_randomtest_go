## 3. 多值与分母

| 类型 | 聚合方式 | 分母及注意点 |
|---|---|---|
| 普通单值 | 每样本累计 | 整组样本数 |
| Serial | 两个 P 均通过计一次；GM Q 类似 | 整组样本数；双 P 不展开两行 |
| NIST 非重叠模板 | 模板子项各一行 | 整组样本数；按 P>0 标记适用，但报表分母仍为整组样本数 |
| NIST 随机游程系列 | 子项各一行 | 子项实际适用数；P≤0 不计适用，可出现 0/0 |
| GM Q | 单样本 Q 门限通过数累计 | 显示和日志保留；GUI 总体结果只按 P |

子项索引从 0 开始，不应直接当作模板编号或随机游程状态值。展开长度取实际算法返回数组。无有效分母当前显示“不通过”；NIST 多值项目录失败清单还有未逐子项判定的兼容行为。解释见 [设计说明书](01_程序设计说明书.md) 和 [使用说明书](02_用户使用说明书.md) 的结果判定章节。
