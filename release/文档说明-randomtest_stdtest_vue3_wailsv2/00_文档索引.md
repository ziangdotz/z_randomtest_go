## 版本与依据

本套文档按实际源码和本次已恢复正常启动的 exe 编制，不将代码注释、标准名称或界面标签视作独立的符合性证明。

| 基线 | 记录 |
|---|---|

| exe 大小 | 11,982,336 bytes |

| Git HEAD | `2bd673333d5907d33f81ad3435968148e8ef17a0` |
| 本地补充修改 | Windows 构建 Makefile 增加发布 exe 的 Medium 完整性标签修正；该修改不改变检测算法 |

源码阅读范围包括桌面模块的 `main.go`、`app.go`、执行与导出模块、Vue 组件、构建配置，以及其直接依赖的 `randomtest_core/suite.go`、`runner.go`、`report/report.go` 和算法入口。

核验记录：

- 原始 exe 仅修改文件完整性标签后成功创建主窗口与 WebView2 子进程；关闭后再次启动成功。原始文件字节及哈希保持不变。
- `randomtest_core` 的 `go test ./report` 通过，覆盖区间计算、报表展开和文件明细判定。
- 运行器的文件/目录对照、非法等级、统计聚合和取消用例通过：`TestSuiteRunnerFileMatchesDirect`、`TestSuiteRunnerDirMatchesDirect`、`TestSuiteGMInvalidLevel`、`TestItemStatApplyOutcome`、`TestSuiteRunnerCancel`。
- 本次核验没有完整执行 1000 样本 GUI 检测、GM 3 级性能测试或所有目标操作系统的兼容测试。示例结果和公式用于解释当前实现，不作为待测数据的检测结论。
